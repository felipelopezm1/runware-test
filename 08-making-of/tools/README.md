# Production tools

The small tools the agents wrote for this production. Node (standard library only) and Python.

**What goes here**

- `log.mjs`: the log tool (numbers steps, screenshots and clips under one lock; `add`, `screen`, `clip`, `import`, `render`, `status`)
- `recordings.mjs`: folds the screen recordings into the record
- `intake/`: `convert.py` (HEIC and MOV to JPEG and posters), `shoot.mjs`, `make_viewer.py` and the viewer
- `director/`: the prompt assembler, the shot and shooting table builders, the bible blocks
- `clerk-build.py`
