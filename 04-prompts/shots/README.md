# Per-shot prompts

The prompts as assembled and sent, one set per shot.

**What goes here**

- `<shot>.frame.txt`, `<shot>.frame.pair.txt`, `<shot>.frame.strip.txt`
- `<shot>.clip.txt`, `<shot>.clip.frame-mode.txt`, `<shot>.clip.reference.txt`
- `faithful/`: the same set with the hand-written shot body verbatim
- `shooting-bodies/`: the director's reshaped bodies and a `.diff.md` per shot
