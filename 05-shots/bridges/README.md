# Bridges

Two short clips filmed on Seedance 2.5 to carry the cut across the scene changes, after the first assembly showed the joins were too hard.

**In this folder**

- `bridge-1-2.mp4`: from the top of the storeroom stairs into the corridor (final), and `bridge-1-2-v1.mp4`, the first try
- `bridge-2-3.mp4`: from the corridor's archway into the roofless hall (final), and `bridge-2-3-v1.mp4`, the first try

The cut that uses them is `is-this-all-on-runware-v3-bridges-1080p` in [`07-cut/`](../../07-cut/).

**Where the files are:** what is committed is in this folder; everything else is in the [Drive folder](https://drive.google.com/drive/folders/1FWxTWA6g5YAU0IvnW3phteEQP4Db5o-Y) under `05-shots/bridges/`, which mirrors these folders. Nothing here points at a private machine.
