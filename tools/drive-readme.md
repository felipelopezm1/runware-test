# Is this all on Runware? The Drive mirror

This folder mirrors the GitHub repository of the film, folder for folder:
https://github.com/felipelopezm1/runware-test

The repository holds everything that fits in Git (the story, the character sheets, every shot's clay clip, takes and pick, the clean cut and its record, the finishing tools, the log and notes, the maps of how it was made) and explains each folder in its README. This Drive folder holds the same folders plus what Git never takes: the 4K films, the full-size panels, the screenshots, the screen recordings and the phone footage.

| --- | --- | --- |
| 00-brief | https://github.com/felipelopezm1/runware-test/tree/claude/project-thread-xs5t14/00-brief | the assessment brief |
| 01-story | https://github.com/felipelopezm1/runware-test/tree/claude/project-thread-xs5t14/01-story | script, shot list, scene direction |
| 02-cast | https://github.com/felipelopezm1/runware-test/tree/claude/project-thread-xs5t14/02-cast | the minis, the character sheets and their full-size panels |
